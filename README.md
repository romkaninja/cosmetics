# Косметическая продукция

OpenServer в этом проекте не используется. Он существует только для Windows и не запускается на macOS. Вместо него выбран Docker Compose: MySQL, PHP и собранный интерфейс поднимаются одной командой и с теми же версиями на Windows и macOS. Отдельно устанавливать PHP, MySQL и Node.js не нужно. Их сборка выполняется внутри Docker.

## Установка

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/) и дождитесь, пока он запустится.
2. Откройте терминал в папке проекта.
3. Выполните:

```bash
docker compose up --build
```

1. Откройте в браузере [http://localhost:8080](http://localhost:8080).

Первый запуск дольше следующих: скачиваются образы, собирается интерфейс и создаётся база. Когда в журнале контейнер `web` запущен, сайт уже доступен.

Остановка: `Ctrl+C` в этом терминале, затем

```bash
docker compose down
```

Чтобы запустить снова в фоне и освободить терминал:

```bash
docker compose up --build -d
```



## База данных

При первом запуске создаётся база `lab_orders`, в неё загружаются `sql/schema.sql` и тестовые данные `sql/seed.sql`.


| Параметр                 | Значение     |
| ------------------------ | ------------ |
| Хост с вашего компьютера | `127.0.0.1`  |
| Порт                     | `3306`       |
| База                     | `lab_orders` |
| Пользователь             | `lab`        |
| Пароль                   | `lab`        |
| Пароль root              | `root`       |


Повторный `docker compose up` не пересоздаёт таблицы и не затирает введённые записи. Чтобы начать с чистой базы и снова загрузить тестовые данные:

```bash
docker compose down -v
docker compose up --build
```

Порты `8080` и `3306` должны быть свободны. Если один из них уже занят другой программой, остановите её перед запуском.
